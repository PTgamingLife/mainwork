# 製作模板(可直接複製填寫)

本檔是 `SKILL.md` 的欄位細節與可複製模板。**只在需要填表時讀取**,不必每次全文載入。

## 0. 製作簡報 BRIEF

```markdown
# BRIEF — <專案代號>
- 用途/平台:
- 片長 / 比例 / 解析度 / 幀率:      例:10s / 9:16 / 1080×1920 / 30fps
- 寫實程度 / 風格 / 節奏:
- 參考作品(連結或描述):
- 主角:身份特徵 / 服裝 / 表演 / 可接受美化程度
- 場景 / 道具 / 車輛 / 產品 / Logo:
- 必須出現:
- 不可出現:
- 音樂 / 音效 / 字幕 / 旁白:
- 交期 / 可接受生成次數 / 點數上限:
- 素材使用權、品牌與肖像風險:
- 假設(缺資料先標,不阻塞):
```

## 5. 影片提示詞模板(產影片)

**核心:固定起始狀態 → 依時間排序的動作 → 結束狀態。**

```
[起始狀態] 畫面從 <起始關鍵幀的狀態> 開始,主體位於 <位置>,鏡頭 <鎖定/運動>
[動作序列]
  0.0–0.8s  <誰先動、動什麼>
  0.8–1.6s  <接著什麼、力道與速度>
  1.6–2.4s  <落點>
[速度曲線] <慢起快收 / 等速 / 突然加速的時間點>
[角色反應] <表情與身體的被動反應>
[物理效果] <重量、慣性、頭髮衣物、粒子、煙塵的先後順序>
[運鏡] <鎖定 / 推 / 拉 / 跟,幅度多少>
[結束狀態] 最後一幀停在 <明確狀態>,以便接 S0X
[禁止] no camera shake, no zoom drift, no text, no logo, no morphing face, <本鏡專屬>
```

**動作因果的寫法範例(照抄這個顆粒度)**

```
先微微往後抗拒 → 嘴巴微張 → 吸力突然增強 → 周邊小物先高速飛入
→ 人物被快速拉向螢幕 → 身體隨漩渦縮小、扭轉並消失
```

❌ 不要寫:「人物被吸進螢幕,很有戲劇感」


## 9. 版本命名

`PROJECT-S##-asset-v##`

- `ENTER-S03-keyframe-v02` — 第 3 鏡的關鍵幀第 2 版
- `ENTER-S03-video-v04` — 第 3 鏡的影片第 4 版
- 檔名全部用 **ASCII**(中文檔名會讓 OpenCV 與 bash 驗證階段炸掉,見 `scripts/autoedit/MODEL.md` 踩坑清單)
