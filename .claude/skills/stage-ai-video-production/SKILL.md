# 分階段 AI 影片製作

## 核心原則

把 AI 影片視為「可審核的鏡頭製作」,不是一次生成完整影片。必須依序通過以下三道門檻:

1. **G1 黑白漫畫劇情確認**
2. **G2 關鍵幀與提示詞確認**
3. **G3 影片生成與成片驗收**

未取得當前門檻的明確確認,不得進入下一階段。沉默、不回覆或模糊意見不算確認。「可以」「繼續」「這版沒錯」只有在明確回應該門檻時,才算通過。

## 絕對限制

- G1 通過前,劇情只能以**黑白漫畫分鏡**呈現。
- G1 通過前,不得產出寫實關鍵幀、彩色概念圖、正式影像提示詞、正式影片提示詞或送出影片生成。
- G2 通過前,不得送出任何會產生影片費用或點數消耗的工作。
- 不得把人物參考照的身份特徵、場景方向、車輛幾何、Logo 字樣交給模型自由發揮。
- 不得在未告知成本、模型限制或預計生成次數時大量重抽。
- 若工具或模型無法遵守已確認規格,先停下並說明落差,不得靜默改劇情。

## 啟動時先建立製作簡報

從使用者資料與附件整理下列資訊。缺少不影響方向的項目可先標示假設;會改變劇情、預算或交付規格的缺口才需要詢問。

- 專案用途與平台
- 片長、直式或橫式、畫面比例、解析度、幀率
- 寫實程度、風格、節奏、參考作品
- 主角身份特徵、服裝、表演與可接受美化程度
- 場景、道具、車輛、產品與 Logo
- 必須出現、不可出現的元素
- 音樂、音效、字幕、旁白需求
- 交付日期、可接受生成次數、預算或點數上限
- 參考素材的使用權、品牌與肖像風險

建立「連續性聖經」:固定人物臉型、髮型、眼鏡、服裝、左右方向、空間配置、車色、駕駛座位置、Logo 正確拼字與其他不可漂移條件。

## G1:只用黑白漫畫描述劇情

### 產出規格

依片長建立黑白漫畫分鏡。十秒影片通常使用 8–12 格;較複雜的動作可增加過渡格。

每格必須包含:

- 鏡號與時間範圍
- 主體位置、視線、肢體動作與表情
- 景別、角度、構圖與鏡頭運動
- 前景、中景、背景與方向關係
- 轉場、節奏、必要音效或特效提示
- 該格必須讓使用者確認的關鍵問題

視覺只能使用黑、白、灰階、墨線、網點與速度線。可以有簡短標註,但不得用彩色或寫實渲染代替漫畫。

### 漫畫分鏡品質檢查

- 靜止畫也能看懂動作順序。
- 左右方向、人物與道具位置前後一致。
- 每個高風險動作都有預備、主要動作與落點。
- 表情節拍可讀,例如抗拒、嘴巴微張、緊張抿嘴、呆滯、白眼。
- 轉場的原因可見,例如漩渦吸力、彈指觸發或跑道展開。
- 片長內放得下,不用靠過快剪輯掩蓋資訊不足。

### G1 停止點

展示完整漫畫與鏡號摘要,請使用者確認「劇情、鏡位、動作、表情、空間方向與節奏」。有修改時只修漫畫並重新確認。取得明確確認後,在製作紀錄標記:

`G1 APPROVED — 漫畫劇情與鏡位已確認`

## G2:產出關鍵幀與提示詞

只有 G1 通過後才開始本階段。

### 先建立鏡頭規格

把每個漫畫格轉成可生成的鏡頭規格:

- 鏡號、時間、預計生成秒數與剪輯使用秒數
- 起始幀、中間動作幀、結束幀
- 景別、鏡頭高度、焦段感、構圖與運鏡
- 演員動作順序、表情與視線
- 場景互動、物理反應、特效與轉場
- 人物、服裝、道具、車輛和 Logo 的連續性限制
- 禁止事項與失敗判定

只為動作、空間或轉場有風險的鏡頭製作多張關鍵幀。簡單鏡頭使用一張起始幀即可;複雜鏡頭使用起始／中間／結束三張。

### 關鍵幀製作順序

1. 鎖定人物主參考、場景主參考、車輛或產品主參考、Logo 原檔。
2. 先做構圖與方向,再做表情、手勢與細節。
3. 逐鏡檢查身份一致性、手指、眼鏡、駕駛座、按鈕位置、車頭角度與背景幾何。
4. 高風險動作用「動作草圖或中間關鍵幀」證明運動路徑,不把全部責任交給文字提示。
5. Logo、標題和精確文字優先後期合成,不要求影片模型生成正確字形。

### 提示詞方法

每個鏡頭分開撰寫:

- **影像提示詞**:身份、服裝、環境、構圖、鏡頭、光線、材質、表情、姿勢、連續性與禁止事項。
- **影片提示詞**:固定起始狀態、依時間排序的動作、速度曲線、角色反應、物理效果、運鏡、結束狀態與禁止事項。

影片提示詞必須描述清楚的動作因果與順序,例如:

`先微微往後抗拒 → 嘴巴微張 → 吸力突然增強 → 周邊小物先高速飛入 → 人物被快速拉向螢幕 → 身體隨漩渦縮小、扭轉並消失`

不要只寫抽象形容詞。使用比例或秒數固定節拍,並寫明哪些物件先動、哪些後動、鏡頭是否鎖定、最後一幀應停在哪裡。

詳細欄位與可複製模板見 [references/production-templates.md](references/production-templates.md)。

### G2 停止點

同時展示:

- 已編號的關鍵幀
- 每鏡影像提示詞
- 每鏡影片提示詞
- 禁止事項與驗收標準
- 預計使用模型、生成秒數、重抽策略與成本上限

收到修改時,仍不得生成影片。更新關鍵幀或提示詞後重新請使用者確認。取得明確確認後標記:

`G2 APPROVED — 關鍵幀、提示詞、模型與成本上限已確認`

## G3:逐鏡生成影片

只有 G2 通過後,才可送出影片生成。

### 生成策略

1. 先檢查模型是否可用、方案權限、解析度、比例、最短秒數、點數與失敗退款規則。
2. 先生成最具代表性或最高風險的一鏡,確認模型能遵守規格。
3. 一次處理一鏡或一個可追蹤的小批次;不要一次把全部點數投入未驗證方法。
4. 保存原始輸出、工作編號、模型、版本、提示詞、參考幀、秒數與費用。
5. 失敗時先判斷是參考幀、提示詞、模型能力還是剪輯可修問題,再決定是否重抽。

### 單鏡驗收

- **身份與解剖**:臉、髮型、眼鏡、年齡、手指、四肢沒有漂移或畸形。
- **空間**:人物左右、上車側、駕駛座、按鈕、車頭方向、背景位置正確。
- **動作**:有預備、施力、主要動作與收勢;重量、慣性與速度可信。
- **鏡頭**:構圖、焦段感、視線與運鏡符合規格,沒有意外漂移或縮放。
- **特效**:吸力層級、漩渦、黑煙、跑道展開等效果按順序發生。
- **內容限制**:沒有意外火焰、文字、Logo、額外人物或物件變形。
- **剪輯邊界**:第一幀與最後一幀可銜接相鄰鏡頭。

不合格鏡頭不可因為「大致可用」直接進入正式剪輯;先記錄缺陷與修正策略。

## 剪輯、聲音與交付

只使用通過單鏡驗收的片段建立粗剪。

1. 依主時間軸裁切,不以生成片段原長度決定節奏。
2. 可用變速對齊節拍,但要重新檢查物理感與表演自然度。
3. 在剪輯階段完成 Logo、精確文字、必要遮罩與接縫特效。
4. 音效需支撐因果:吸力前兆、物件飛入、漩渦、彈指、車輛啟動失敗、黑煙、再次彈指與 Logo 音標。
5. 輸出接觸表、轉場邊界幀或低解析預覽做最後檢查。
6. 最終輸出前確認片長、比例、解析度、幀率、音量、色彩、Logo 安全區與平台壓縮。

## 修改時回到正確門檻

- 改劇情、鏡頭順序、角色目標或結局:退回 G1。
- 改構圖、角色方向、服裝、車位、表情或關鍵動作路徑:退回 G2 關鍵幀。
- 只改動作速度、物理效果、運鏡或負面限制:退回 G2 提示詞。
- 只改裁切、變速、聲音、字幕或 Logo 時點:留在剪輯階段。

每次退回都只重做受影響的鏡頭,保留已確認且未受影響的資產。

## 成本與版本紀錄

為每次生成記錄:日期、工具、模型、工作編號、資產版本、生成秒數、點數或現金、是否採用、失敗原因。分開呈現:

- 實際新增現金支出
- 訂閱內已包含的點數消耗
- 影像與影片生成點數
- 可取得時的文字 Token 用量與估算費用
- 未公開費率或無法查得的項目,明確標記「未知」,不得捏造

版本命名使用:`PROJECT-S##-asset-v##`,例如 `ENTER-S03-keyframe-v02`、`ENTER-S03-video-v04`。

## 完成定義

專案只有在下列項目齊全時才算完成:

- G1 黑白漫畫分鏡與確認紀錄
- G2 關鍵幀、影像提示詞、影片提示詞與確認紀錄
- 每鏡生成紀錄與成本台帳
- 通過驗收的鏡頭清單
- 粗剪、修改紀錄與最終成片
- 可重現的專案檔、Logo／字幕資產與交付規格

## 溝通方式

使用使用者的主要語言說明創作決策。模型提示詞可使用最適合該模型的語言,但要提供使用者能審核的摘要。每次只要求確認當前門檻,清楚列出「已鎖定」「待確認」「不會在本階段執行」三項,避免把確認與付費生成混在一起。

# 本工作台的接線(mainwork 專用)

以上是通用製作法。以下把它接到這個工作台既有的三個系統,避免各做各的。

## 一、兩條產線,同一組門檻

| 產線 | 什麼情況 | 走法 |
|---|---|---|
| **A · 敘事線**(完整 AI 影片) | 整支片都是 AI 生成鏡頭:短片、廣告、作品集、角色一致性影片 | 走**完整 G1/G2/G3**,上面全文照做 |
| **B · B-roll 線**(口播片插入) | 主體是我的口播,只有幾段要切 B-roll(`scripts/autoedit/` 的第四章) | 走**快線**(下方),門檻不減、產出規格壓縮 |

判斷:**這支片的敘事重量在 AI 畫面上,還是在我的口說上?** 在畫面上 → A;在口說上 → B。

## 二、B-roll 快線(A 線的壓縮版)

B-roll 每段只有 3–7 秒、蓋在口播上、觀眾注意力還在字幕,不值得畫 8–12 格漫畫。但**三道門檻一格都不能少** —— 因為 Higgsfield 的 `generate_video` 一次就燒點數,那是不可逆支出。

| 門檻 | A 線(敘事) | B 線(B-roll) |
|---|---|---|
| G1 | 8–12 格黑白漫畫 | **一句話分鏡**:哪句字幕 + 這段要「演出什麼語意」+ 起訖秒數。**用文字,不畫圖**,但仍要我明確點頭 |
| G2 | 關鍵幀 + 影像/影片提示詞 + 成本上限 | **影片提示詞 + 預估點數**(`get_cost:true` 先估),寫清楚動作順序;只有身份/場景要連續的鏡頭才做起始幀 |
| G3 | 逐鏡生成 + 完整驗收表 | 逐段生成 + **B-roll 驗收 6 項**(下方),過了才進 `edit_plan` |

**B-roll 快線的 G1 一句話分鏡格式**
```
S01 | 字幕「這件事我做了三年」 | 68.0–74.0s | 語意:時間流逝的桌面,同一張桌子四季換過去 | 直式 9:16
```

## 三、成本閘(接 CLAUDE.md 的 🔒 權限安全閘)

**`generate_video` / `generate_image` / `upscale_*` 一律視為「不可逆對外動作」**,與 push、Threads 發文同級:

- G2 未通過 → **一次都不准送**。這條蓋過「先試一張看看」的直覺。
- 送出前必用 `get_cost:true` 估,把「這鏡幾點、總共幾點、佔今天上限多少」寫給我看。
- 單鏡重抽 **上限 2 次**;第 3 次前停下來,先講「是參考幀、提示詞、還是模型能力問題」,由我決定要不要繼續燒。
- 參考規格:`kling3_0_turbo`、`9:16`、5 秒 ≈ 7.5 點(`scripts/autoedit/MODEL.md` 第四章)。

## 四、B-roll 單鏡驗收 6 項(A 線的 7 項驗收在 B 線的縮版)

1. **身份/場景連續**:同一支片的多段 B-roll,風格、色溫、寫實程度一致,不能一段動畫一段實拍。
2. **方向與構圖**:直式 9:16 滿版,主體不被 1080×1920 的 crop 切掉;安全區避開底部字幕帶與 `y=150` 貼圖帶。
3. **動作因果**:有預備 → 主要動作 → 落點,不是一團漂移的雲。
4. **沒有意外文字/Logo**:AI 生成的假字最傷質感;字一律後期用 `stickers.py` 疊。
5. **首尾可銜接**:第一幀與最後一幀切回口播不跳。
6. **秒數 ≥ 需求秒數**:生成秒數要比 `overlays` 的 `end-start` 長一點,留裁切餘裕。

不合格 → **不准填進 `edit_plan.json`**。記下缺陷再決定重抽或換手法。

## 五、交接:G3 通過 → autoedit 後製

驗收過的片段用 `curl` 從 `job_display` 的 `rawUrl` 下載,然後接回既有管線:

```
1. python scripts/ae.py plan 口播.mp4 -o out/     # 抓字幕列句
2. 逐句點選 → 這幾句要 B-roll → 本 skill 的 G1/G2/G3 產出 clip
3. 填 edit_plan.json:
   {"type":"broll","clip":"S01_v02.mp4","start":68,"end":74}
4. python scripts/ae.py render out/edit_plan.json -o 成品.mp4   # 放背景跑
```

**Logo、標題、精確文字、計數器一律不交給影片模型** —— 用 `scripts/autoedit/stickers.py` 在後期疊(這正好是本 skill「精確文字優先後期合成」那條原則,在這個工作台的實作)。

## 六、與其他 skill 的分工(別互相蓋台)

| 問題 | 歸誰 |
|---|---|
| 這支片要講什麼、hook 怎麼下、CTA 是什麼 | `/reels-script` |
| 每句配什麼貼圖、節奏怎麼排、怎麼上字幕 | `scripts/autoedit/MODEL.md` |
| **AI 生成的畫面怎麼從劇情走到成片、花多少點數** | **本 skill** |

三者的交界:`/reels-script` 給腳本 → autoedit `plan` 把腳本切成句 → **本 skill 把需要 B-roll 的句子變成畫面** → autoedit `render` 合成。

|---|---|---|---|---|---|---|---|---|

現金支出與訂閱內點數**分開兩列小計**;查不到費率的填「未知」,不估、不編。
