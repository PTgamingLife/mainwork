# AI 秘書形象角色(3D 圓球精靈)

## 一句話用途
AI 秘書建置事業的品牌形象角色,可用於 LINE OA 頭像、圖文選單、Flex 卡片、宣傳素材。

## 檔案位置
- `dm-ai-secretary/mascot/ai_secretary_mascot_profile.png` — 形象照(正面、淺蜜桃粉背景、1024×1024;無尾巴的正面定稿)
- `dm-ai-secretary/mascot/ai_secretary_mascot_front.png` — 正面,透明背景
- `dm-ai-secretary/mascot/ai_secretary_mascot_left.png` — 左側面,透明背景
- `dm-ai-secretary/mascot/ai_secretary_mascot_back.png` — 背面,透明背景
- `dm-ai-secretary/mascot/ai_secretary_mascot_right.png` — 右側面,透明背景

## 怎麼用
直接當圖片素材使用。四張透明 PNG 皆為 1024×1024 RGBA。

角色設定(要生成新姿勢/新角度時沿用):奶油白正圓球身體、無手、兩隻小腳、
蜜桃粉耳機(麥克風在角色左側)、頭頂蜜桃粉「倒 A」天線、大圓黑眼、小微笑、粉腮紅、
下背部奶油白短圓尾巴;霧面黏土 3D 公仔質感。

## 注意事項 / 已知限制
- 四張透明圖是分開生成的,角色大小略有差異(正面略小),並排使用需自行統一縮放。
- 透明圖為綠底生成後本地去背,非原生透明。
- LINE OA 頭像、封面等對外更換屬發佈動作,執行前需先問使用者。
