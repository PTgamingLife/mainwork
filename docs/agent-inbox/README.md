# agent-inbox — 工具交付區

各 session 做好的工具/資料,用 `/handoff` 交付到這裡;agent session 用 `/inbox` 收取。

- `YYYY-MM-DD-<名稱>.md` — 待收的交付單(`status: new`)
- `done/` — 已收取歸檔
- `TOOLBOX.md` — agent 的工具總表

規則:
- 雲端 session 只看得到**已合併進 main** 的內容。
- 金鑰不進這裡、不進 git;交付單只寫需要的變數名。
- 大型資料放 Google Drive / Supabase Storage,這裡只放連結。
