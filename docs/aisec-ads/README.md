## 三、拍攝清單

### 共通規格
- 9:16 直式、1080×1920、30fps；手機螢幕錄影也用直式。
- 螢幕錄影前開**勿擾模式**；示範客戶一律**假名、假電話**。
- 實拍：窗邊自然光、手機架穩、收音靠近嘴（領夾麥最好）。

### 先準備：示範對話（客戶「王先生」）
用另一支手機／帳號扮演王先生，**分 3–4 天**傳，至少 15 則，閒聊越多越好：

```
（11/10）王：最近在想小孩教育金的事
（11/10）你：可以啊，找時間幫你算看看
（11/10）王：好啊，最近忙到爆，月底結帳
（11/11）王：下週三下午 3 點可以嗎？在公司附近星巴克
（11/11）你：沒問題
（11/12）王：對了 12/5 是我太太生日，想順便看看她的保單
（11/12）王：我那張壽險 3 月到期，要記得提醒我
（11/12）王：哈哈我自己一定會忘
（11/13）王：週三我會帶我太太一起去
……再加 6–8 則日常閒聊（天氣、球賽、小孩）
```

## 五、剪輯規格

- **版式**：卡片收合（MODEL.md 第 23 條）——背景鋪奶油米 `#FFF8EC`，影片縮成圓角卡片放下半部，上半部放大字卡。V4 例外：全屏講者。
- **色彩**（與報名頁一致）：主文字 `#3B2A1E`、強調綠 `#4CAF50`、木頭棕 `#8B5E3C`、黃色註解 `#F2C14E`。
- **字型**：Noto Sans TC 900（大字卡）／700（字幕）。
- **節奏**：每 2–3 秒一次視覺變化，靜止不得超過 3 秒。
- **字幕**：口白逐句上字幕（白底深字或深底白字，放安全區內）；**雙層字幕**：主層＝口白，黃色註解層＝`*手法`（第 18 條）。
- **進度條**：V1 畫面底部 3 節點 `整理 ─ 行事曆 ─ 提醒`，依序點亮（第 20 條）。
- **黃色螢光筆**：V1 3–8 秒在三句訊息上依序刷黃，每句間隔約 1.5 秒。
- **音樂**：輕快背景音樂，音量低於旁白 15 dB 以上；關聲音也要看得懂。
- **輸出**：`V1_forget.mp4`、`V2_remind.mp4`、`V3_seats_X.mp4`、`V4_why7.mp4`；H.264、1080×1920、30fps。
- **工具**：`scripts/ae.py`（見 `scripts/autoedit/MODEL.md`）。⚠️ ae.py 預設不裁切；V4 需要 jump cut，剪輯 session 自行處理靜音段。
- **檢查**：輸出後截關鍵幀確認字卡沒有被 IG 介面（上方、下方、右側按鈕區）蓋住。
