# 十神能量系統 v1(階段一:系統化)

> 狀態:2026-10-19 使用者已確認「內/外軸」取代傳統陰陽分法。
> 與傳統命理衝突處見 `03-tradition-check.md` §A。

## 1. 兩個維度

**維度一:五種能量(五行階段)**,依「生」的方向循環:

```
自我(比劫) → 表達(食傷) → 資源(財) → 控制(官殺) → 確定(印) → 自我
```

**維度二:方向**
- **內**:調節自己(對自己的標準、累積、規則、知識)
- **外**:作用於環境(對他人、對機會、對局面、對經驗)

| 能量 | 內 | 外 |
|---|---|---|
| ① 自我 | **比肩**:想法一致的同類 | **劫財**:想法不同但背景/條件相近的人脈 |
| ② 表達 | **食神**:自我滿足的創作 | **傷官**:爭取他人認可的表達 |
| ③ 資源 | **正財**:自我管理、穩定累積 | **偏財**:觀察環境、整合機會 |
| ④ 控制 | **正官**:要求自己守規、按步調 | **七殺**:掌控身邊人事物完成目標 |
| ⑤ 確定 | **正印**:知識/理論帶來的確定性 | **偏印**:經驗/玄學帶來的確定性 |

## 2. 構念的操作化(要能被量測)

| 格 | 操作定義 | 代理量表(既有、可查) |
|---|---|---|
| 比肩 | 與理念相同者的認同強度 | 社會認同量表、Need to Belong Scale |
| 劫財 | 同條件人脈的規模與往來頻率 | 社會網絡規模/弱連結數 |
| 食神 | 為自己滿意而創作的時間與投入 | 內在動機(SDT)、心流頻率 |
| 傷官 | 主動公開表達、爭取關注的頻率 | 自我呈現/自我推銷量表 |
| 正財 | 預算、儲蓄、延遲滿足 | 財務自控、延遲折扣 |
| 偏財 | 察覺並行動於新機會 | 創業警覺性量表 |
| 正官 | 自律、守規、按計畫 | 盡責性、Brief Self-Control Scale |
| 七殺 | 想影響/掌控他人與局面 | 權力需求、個人權力感量表 |
| 正印 | 透過理解/理論消除不確定 | 認知需求量表(NFC-cognition) |
| 偏印 | 透過經驗/信念消除不確定 | 結束需求(Need for Closure)、控制感 |

> **重要**:量表分數(**現況**)與八字推算分布(**先天**)永遠分兩欄記錄。
> 本系統的科學驗證對象是「能量之間的因果關係」(H1–H10),
> 不是「八字能否預測性格」——後者已有反證(見 `02-evidence.md` §0)。

## 3. 十條假設

### 相生(A↑ → B↑)

| 編號 | 關係 | 機制 | 可推翻條件 |
|---|---|---|---|
| H1 | 自我 → 表達 | 有歸屬與自我價值,才敢在人前展現才華 | 歸屬/自尊與表達無正相關;操弄歸屬感後表達不變 |
| H2 | 表達 → 資源 | 表達 × 專業 × 具體計畫 → 取得資源 | 表達高、計畫高,資源仍不增 |
| H3 | 資源 → 控制 | 資源透過契約/依賴關係轉成權力與控制感 | 資源增加,控制感不變 |
| H4 | 控制 → 確定 | 權力/控制感降低焦慮,形成護城河 | 權力↑而安全感不變或↓ |
| H5 | 確定 → 自我 | 安全感高 → 敢擴展社群 | 安全感與社交擴張無關 |

### 相剋(A↑ → B↓,或 A 約束 B 的過度)

| 編號 | 關係 | 機制 | 可推翻條件 |
|---|---|---|---|
| H6 | 自我 ⊣ 資源 | 追求平等/融入 → 分享、資源外流 | 群體認同與個人累積無負相關 |
| H7 | 資源 ⊣ 確定 | KPI/外在報酬 → 壓縮探索與求知 | 績效壓力不減少探索 |
| H8 | 確定 ⊣ 表達 | 系統化/結構 → 收斂發散的表達 | 結構不影響發散量 |
| H9 | 表達 ⊣ 控制 | 創新/原創 → 挑戰既有規則 | 創造力與守規無負相關 |
| H10 | 控制 ⊣ 自我 | 規範 → 抑制群體過度凝聚或擴大 | 規範強度與群體凝聚無關 |

## 4. 調節規則(遊戲任務的引擎)

設某格分數為 S,平均為 μ:

| 狀態 | 傳統說法 | 本系統規則 | 對應任務 |
|---|---|---|---|
| S 過高 | 旺者宜剋、宜洩 | ① 用**剋它**的能量設限;② 用**它所生**的能量宣洩 | **戒律** |
| S 過低 | 弱者宜生扶 | 用**生它**的能量補 | **約束**(限時挑戰) |
| 兩能量相戰 | 通關 | 用兩者中間的能量轉換(例:控制剋自我 → 用「確定」通關) | 約束的進階版 |
| 使用者自訂 | 用神 | 依目標選一格當主軸 | **誓言** |

> 實作時「過高/過低」= 與平均差 ±40% 以上(可調)。

## 5. 驗證流程(可重複)

1. **測**:10 格量表(每格 2–3 題,1–5 分)。
2. **追蹤**:每天打卡記錄任務完成與 10 格自評的變化。
3. **檢驗**:以面板資料(panel data)檢驗 H1–H10 的「前一期 A → 後一期 B」關係(cross-lagged)。
4. **判定**:每條假設依證據等級標示 支持 / 部分支持 / 不支持 / 待測。
5. **迭代**:不支持的連結要改寫機制或從系統中移除——不硬凹。
