# 階段三:和傳統命理比對

> 依據的傳統典籍:《淵海子平》《三命通會》《子平真詮》《滴天髓》《窮通寶鑑》。
> 判定標記:✅ 吻合 / 🟡 部分吻合 / ❌ 衝突 / ⬜ 本系統沒有對應

## A. 本系統與傳統命理書的衝突清單

| # | 項目 | 傳統說法 | 本系統做法 | 處理方式 |
|---|---|---|---|---|
| A1 | 十神的第二維度 | 依**陰陽同異**分:同性為比肩、食神、偏財、七殺、偏印 | 依**內/外**分:內為比肩、食神、正財、正官、正印 | ✔ 使用者已確認採用內/外。食傷這組與陰陽方向相反,其他組一致 |
| A2 | 七殺的主體 | 七殺 = **剋我**的力量:壓力、小人、危難,是外界加諸於我 | 七殺 = **我**對外的控制力 | 🟡 傳統要「制殺」「殺為我用」(如食神制殺、殺印相生)後,七殺才轉為我的魄力。遊戲裡把「掌局」定義成**已被駕馭的七殺** |
| A3 | 劫財的語意 | 劫財 = 競爭者、奪財、衝動、豪賭 | 劫財 = 想法不同但條件相近的人脈 | 🟡 保留「同條件」這個核心,另外加上傳統的**競爭**面向:同盟也是對手 |
| A4 | 食神的語意 | 食神 = 享受、口福、溫和表達、壽元 | 食神 = 對內的才華、自我滿足 | ✅ 大致吻合,「享受」可以併入匠心的定義 |
| A5 | 六親 | 十神同時代表父母、配偶、子女、兄弟 | 不處理六親 | ⬜ 刻意排除:遊戲只談能力,避免談論家人的命運 |
| A6 | 日主強弱 | 先判斷身強或身弱,才能決定喜忌 | 只看十格分布的高低 | 🟡 MVP 用「與平均的差距」近似;v2 再加入日主強弱 |
| A7 | 從格/化格 | 某一神極旺時要**順著它**,不能剋 | 過高一律設戒律 | ❌ 衝突。規則改成:某格占比 > 45% 時,戒律改為「**引流**」(用它所生的能量宣洩),不再壓制 |
| A8 | 調候 | 寒暖燥濕(依出生季節)優先 | 沒有季節維度 | ⬜ v2 才考慮 |
| A9 | 相乘相侮 | 剋的一方太弱時會被反剋(如財多身弱、木多金缺) | 剋只有單向 | 🟡 證據也顯示雙向(H9),v2 加入「反剋」 |
| A10 | 合 | 天干五合、地支六合/三合,具有羈絆與轉化效果 | 沒有「合」 | ⬜ 見 §C3,很值得加入 |
| A11 | 刑、破、害 | 地支的特殊關係 | 沒有對應 | ⬜ 見 §C4 |
| A12 | 時辰邊界 | 子時有早晚子之爭 | 23:00 起算隔日 | 🟡 採最常見的做法,並在介面上說明 |

## C. 其他命理概念的檢驗

### C1. 驛馬(依傳統定義)
- **定義**:以年支或日支的三合局查詢——申子辰馬在寅、寅午戌馬在申、巳酉丑馬在亥、亥卯未馬在巳。馬落在四柱任一支即「帶驛馬」。主奔波、遷動、外出。
- **與本系統的關係**:❌ **結構上無關**。驛馬是**地支組合**,和十神分布無關。你提出的「十神多而分散所以要移動」是一種新詮釋,傳統沒有這樣說。
- **可以怎麼驗證**:帶驛馬的人,年均移動次數/旅行天數是否較高(可在遊戲內收集)。目前沒有實證研究支持。
- **遊戲處理**:以傳統定義計算,顯示為「**行旅星**」徽章,文案寫「傳統說法」,不宣稱有科學依據。

### C2. 沖(六沖:子午、丑未、寅申、卯酉、辰戌、巳亥)
- 子午(水火)、卯酉(木金)、寅申、巳亥這四組:兩支的本氣**相剋** → 🟡 可視為「剋」加上「變動」。
- 丑未、辰戌:**同屬土**卻相沖 → ❌ 無法用生剋解釋;它來自地支圓盤上的**對角位置**(幾何關係)。
- **結論**:沖 ≠ 剋。在遊戲裡定義成「**震盪**」:提醒那一格的能量最近容易不穩。

### C3. 合(天干五合:甲己、乙庚、丙辛、丁壬、戊癸)
- 發現:天干五合**都是**陽干與它的**正財**相合(反過來看,陰干與它的正官相合)。
- 這正好呼應你原文 H3 的「**透過契約把資源轉成權力**」→ ✅ **合 = 契約/羈絆**。
- 建議:v2 加入「結盟」機制——兩位玩家的命盤有天干五合,就給予合作任務加成。

### C4. 刑、害、破
- 三刑(寅巳申、丑戌未、子卯、自刑)、六害、六破都是**位置關係**,不是能量關係。
- ⬜ 本系統無法對應,也沒有心理學研究可以驗證。**不納入遊戲**,避免負面標籤(「你命中帶刑」容易造成焦慮)。

### C5. 神煞
| 神煞 | 傳統定義 | 與十神的關係 | 判定 |
|---|---|---|---|
| 羊刃 | 陽干的帝旺位(甲在卯…) | = 極旺的劫財 | ✅ 正好說明「過高的能量需要戒律」,傳統解法「羊刃駕殺」= 用律制群 |
| 文昌 | 甲在巳、乙在午… | 多數日干(甲乙庚辛壬癸)的文昌,正是其「食神」的祿位 | 🟡 文昌近似「食神得地」→ 匠心的加成(丙丁戊己的推法另有流派差異) |
| 華蓋 | 三合局的墓庫 | 主孤高、藝術、宗教 | 🟡 語意接近偏印(閱歷/玄學),但計算方式無關 |
| 桃花 | 三合局的沐浴位(子午卯酉) | 主人緣 | 🟡 語意接近傷官/劫財,但計算方式無關 |
| 天乙貴人 | 依日干查 | 無 | ⬜ |
| 空亡 | 旬空 | 無 | ⬜ 不納入(負面標籤) |

### C6. 用神、通關、病藥
- 用神(《子平真詮》):找出能平衡命局的那個十神 → ✅ 即本系統的「調節規則」。
- 通關(《滴天髓》):兩神相戰,用中間的一神調和 → ✅ 已寫進 `01-system.md` §4。
- 病藥:命局的「病」是過旺或受剋,「藥」是對應的十神 → ✅ 即**戒律**的設計原理。

## D. 總結

1. **十神生剋十條全部能在傳統格局語言裡找到對應**,而且其中 H6、H7、H8 有很強的心理學證據。
2. 真正衝突的只有:陰陽改內外(A1)、七殺主體(A2)、從格(A7)。A7 已在遊戲規則中修正。
3. 驛馬、桃花、華蓋等**神煞是依地支位置計算**,跟十神能量模型在結構上無關;只能當「傳統說法」的彩蛋,不能當作系統推論。
4. 「合 = 契約」是一個意外的吻合,建議下一版加入。
