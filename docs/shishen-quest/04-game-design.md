## 2. 頁面

1. **入門**:輸入生日、時辰(可勾選「不知道時辰」)與暱稱
2. **命盤**:四柱、十格能量條、五能量雷達圖、最高與最低的解讀、行旅星(驛馬)徽章
3. **自評**:10 題,每題 1–5 分 → 「現況」雷達,和「先天」雷達疊在一起比較
4. **三誓**:系統建議**戒律**(最高的一格)和**約束**(最低的一格,7 天),**誓言**由使用者自己寫(附範例);可以換一個建議
5. **今日**:三項打卡 + 一句墨語(隨機台詞)
6. **修行**:連續天數、境界、護符數量、14 天打卡熱度、歷程

## 3. 規則

- **戒律**:選分數最高的一格。占比 > 45% 時改成「引流」(用它所生的能量宣洩,對應從格)
- **約束**:選分數最低的一格,從生它的能量出發,7 天後結算
- **誓言**:30 天,每天可以回報進度 0–100%
- **境界**(依累積打卡天數):初心 0 / 入門 3 / 精進 10 / 通達 21 / 大成 45
- **護符**:每連續 7 天得 1 枚;斷一天時自動使用,保住連續天數
