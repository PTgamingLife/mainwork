# LadyS 部署包(可從零重建)

> 不含任何個人資料。`<…>` 請換成你自己的值;**金鑰一律放 Supabase secrets,不要進 git**。

## 一、前置準備
1. Supabase 專案(記下 `<PROJECT_REF>`),啟用 `pg_cron`、`pg_net`、`pgcrypto`(`extensions` schema)。
2. LINE Official Account + Messaging API 頻道(取得 Channel secret、Channel access token)。
3. LINE LIFF(取得 `<LIFF_ID>`,Endpoint 指向你的網頁位置;其 Channel ID 為 `<LIFF_CHANNEL_ID>`)。
4. Anthropic API key。
5. (選用)Google Cloud OAuth 憑證(scope:`calendar.events`),並建立一個專用日曆。
6. 靜態網頁空間(例如 GitHub Pages)放 `ladys/`。

啟用排程(憑證設好之後才下):
```sql
select cron.schedule('ladys-tick', '*/5 * * * *', $$select public.ladys_tick()$$);
```
`ladys_tick()` 會依設定時間(預設 07:30 / 23:00)呼叫 morning / nightly,金鑰取自 `ladys_push_auth`。

## 五、Edge Functions(全部 `verify_jwt=false`,自行驗簽 / 驗權)
| 函式 | 依賴的 `_shared` 檔 |
|---|---|
| `ladys-webhook` | ladys、extract、gcal、life、image、memo、obsolete、work、eventnote |
| `ladys-nightly` | ladys、extract、gcal、life、obsolete、work、eventnote |
| `ladys-morning` | ladys、life |
| `ladys-api` | ladys、gcal、life |
| `ladys-setup-richmenu`(一次性) | ladys |
| `ladys-card-preview`(開發預覽,可省略) | ladys |

`_shared/ladys-extract.ts` 另會 import `ladys-obsolete`、`ladys-eventnote`;`ladys-memo.ts` import `ladys-image`、`ladys-extract`。部署時整個依賴鏈的檔案都要一起上傳。

```bash
supabase functions deploy ladys-webhook  --no-verify-jwt --project-ref <PROJECT_REF>
supabase functions deploy ladys-nightly  --no-verify-jwt --project-ref <PROJECT_REF>
supabase functions deploy ladys-morning  --no-verify-jwt --project-ref <PROJECT_REF>
supabase functions deploy ladys-api      --no-verify-jwt --project-ref <PROJECT_REF>
```

## 六、啟用順序
1. 套 migrations → 設 secrets → 部署 4 支函式。
2. LINE 後台:Webhook URL = `…/functions/v1/ladys-webhook`,開啟 Use webhook,關閉自動回應。
3. 部署 `ladys/` 到靜態空間,LIFF Endpoint 指向 `ladys/index.html`。
4. 把機器人拉進家庭群組,輸入 `LadyS 綁定 <LADYS_BIND_CODE>`(綁定者 = 老公,第二位發言者 = 老婆)。
5. (選用)執行 `ladys-setup-richmenu` 設定圖文選單(圖:`ladys/richmenu.png`)。
6. (選用)Google 日曆:在 `ladys_settings` 填 `ladys_gcal_enabled=true`、`ladys_gcal_calendar_id`;日曆分享給另一位。
7. (選用)工作群:拉進群組後輸入 `LadyS 紀錄 <LADYS_BIND_CODE>`。
8. 排程:執行第二節的 `cron.schedule`。

## 七、驗收清單
- [ ] 群組輸入「選單」收到卡片。
- [ ] 群組說「明天 10 點看牙醫」→ 輸入「更新行事曆」→ 收到整理卡。
- [ ] LIFF 可開啟、可新增 / 修改行程。
- [ ] 說「改成後天」→ 出現刪除確認卡;說補充資訊 → 出現補備註確認卡。
- [ ] 回覆一張圖輸入「記憶圖片」→ 有結果。
- [ ] `ladys_runs` 隔天出現 morning / nightly 紀錄。
- [ ] Google 日曆出現同步的行程(若啟用)。

## 八、維運備註
- 部署後 LINE 後台按 Verify 應回 200(空事件)。
- 查問題:Supabase Edge Function logs(`ladys event error`、`ladys gcal`、`ladys nightly error`)。
- 備份:各 `ladys_*` 表為主要資料;`ladys_messages` 與 `ladys_images` 為暫存,無需備份。
