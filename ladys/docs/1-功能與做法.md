# LadyS 生活秘書 — 功能與做法

LINE 家庭秘書機器人:夫妻兩人在 LINE 群組聊天,秘書安靜記錄,每晚用 AI 整理成行程 / 記帳 / 待辦 / 目標 / 生活紀錄,早上推播今日行程,並提供 LIFF 網頁管理與 Google 日曆單向同步。

> 本文件已移除所有個人資訊(使用者 ID、群組 ID、姓名、金鑰、專案代號)。`<…>` 為需自行填入的占位。

## 一、總覽

```
LINE 家庭群組 ──訊息──▶ ladys-webhook ──存入──▶ ladys_messages(原文,整理後立刻刪除)
                          │  指令 / 按鈕 → 用 reply 回覆(不扣推播額度)
pg_cron(每 5 分鐘) ─▶ ladys_tick() ─▶ ladys-morning(早上推播)/ ladys-nightly(晚間整理)
ladys-nightly ─▶ _shared/ladys-extract.ts ─▶ Claude Haiku 5.5 結構化輸出 ─▶ 寫入各資料表 ─▶ Google 日曆同步 ─▶ 推播整理卡
LIFF 網頁(ladys/) ─idToken─▶ ladys-api ─▶ 同一組資料表
```

## 二、功能領域(依用途分類)

### 1. 行事曆 / 行程
- 自動:晚間整理時,從對話抽出有日期的事 → `ladys_events`(標題、日期時間、結束時間、地點、**備註**、負責人、是否每年重複)。
- 相對日期(明天、下週三)以「該則訊息送出日」換算。
- 每年重複:生日、紀念日 → `yearly=true`,顯示「第 N 週年」,早上倒數提醒。
- 重複事件去重:AI 會拿到「未來 60 天已存在行程」清單(含現有備註摘要),不重複新增。
- 手動:LIFF 可新增 / 修改 / 刪除(備註欄 300 字)。
- 指令「行程」:回覆未來 7 天。

### 2. 行程異動確認(改期 / 取消 / 補充)
| 情境 | 做法 | 結果 |
|---|---|---|
| 對話說某筆改期或取消 | AI 填 `obsolete`(引用 `E<編號>`) | 發「🗑️ 刪除 / 保留」確認卡,按了才軟刪除 + 同步 Google |
| 對話在補充某筆既有行程 | AI 填 `event_notes`(引用 `E<編號>`) | 發「📝 補到備註 / 略過」確認卡,按了才接到備註(≤300 字,已含則不重複) |
- 兩種都只認一般行程,不動每年重複的紀念日。
- 確認卡按鈕為 postback,webhook 以「先把狀態從 pending 改掉才執行」防止連按重複。
- 補充卡存 `ladys_pending`(kind=`event_note`),7 天未按作廢。

### 3. 記帳(支出 / 收入)
- 自動抽出:支出、收入(`ladys_expenses.ladys_flow` = out / in),分類固定清單(支出:餐飲、交通、日用品、居家、育兒、醫療、娛樂、服飾、禮金、其他;收入:薪資、獎金、接案、投資、其他)。
- 指令「帳」:本月支出、收入、結餘、各人合計、最近 5 筆。
- LIFF 記帳頁四個分頁:月支出 / 年支出 / 月收入 / 年收入。

### 4. 待辦與目標
- 無日期要完成的事 → todo;長期方向(可衡量、含期限)→ goal(`ladys_notes`)。
- 指令「待辦」(同義「瑣事」)、「目標」;LIFF 可勾選完成。

### 5. 生活紀錄(`ladys_life`)
- 經期(開始 / 結束)、健康狀況、其他值得記住的生活細節。
- 經期統計:最近一次、平均週期(只採 15~60 天、取最近 6 次)、預測下次。
- 隱私:經期紀錄不進群組卡片,只顯示「🔒 私密紀錄 N 筆」;預測提醒用一對一私訊(可設定給老婆 / 兩人 / 關閉)。

### 6. 圖片記憶
- 群組傳圖:只記訊息編號(`ladys_images`),**不存圖片**,7 天自動清除。
- 指令(需「回覆」某張圖後輸入):
  - 「記憶圖片」:處理被回覆的那一張。
  - 「記憶以上圖片」/「記憶以下圖片」:從被回覆那張起到下指令為止,最多 20 張,每批 5 張並行讀取。
- AI 讀圖(逐張判讀):
  - `action`(喜帖、預約、帳單、收據…)→ 走一般整理流程,發整理卡。
  - `reference`(說明書、規格、地址、保單、菜單…)→ 拆成最多 5 個重點存生活紀錄「其他」,群組只回一行「📁 已存入生活紀錄:…」。
- reply token 過期(讀圖太久)→ 自動改用推播。

### 7. 工作群組(只記錄、不說話)
- 以「LadyS 紀錄 <綁定碼>」綁定(須為成員或帳號擁有者),最多 5 個。
- 每晚整理成「待確認項目」(行程 / 待辦 / 支出 / 收入,一律算老公,標 💼),在家庭群組發確認卡:逐筆「✅ 加入 / ✖️ 略過」或「全部加入」;7 天未按作廢。
- 工作群原文整理後立刻刪除。

### 8. 排程推播
- 早上(預設 07:30,可設定):今天 + 明天行程、紀念日倒數;今天沒行程可選擇推「今天沒有安排」。**不呼叫 AI**。
- 晚間(預設 23:00,可設定):整理 + 推播整理卡(整理卡 + 確認卡 + 工作群卡合併一次推播,最多 5 則 = 算 1 次額度)。
- 立即整理:指令「更新行事曆」(用 reply,不扣額度)。
- 每種排程每天只跑一次(`ladys_runs` 唯一鍵搶佔)。

### 9. Google 日曆同步(單向)
- LadyS 是唯一來源,Google 上手動改不會回寫。
- sweep 找出「沒同步過 / 被改過(dirty)/ 已刪除但 Google 還在」的行程,一次最多 50 筆;顏色依負責人。
- 描述欄 = 備註 + 同步說明;資料庫 trigger 在標題、時間、地點、負責人、重複、備註變動時標記 dirty。

### 10. LIFF 管理介面(`ladys/`)
- 頁面:行事曆、列表、記帳、目標、待辦、生活、設定;按鈕 / 圖文選單開啟。
- 設定:口吻(管家 / 秘書 / 朋友 / 自訂)、推播時間、抽取開關(行程 / 記帳 / 待辦)、成員稱呼、Google 日曆、解除工作群。
- 驗證:前端取 LIFF idToken → `ladys-api` 向 LINE 驗證 → 只有成員或帳號擁有者可操作。

### 11. 安全與隱私
- 落地前遮蔽:身分證、手機、卡號、密碼 / 驗證碼 / PIN、銀行帳號(`ladysMask`);AI 提示也禁止記錄敏感資料。
- 原文即用即刪:群組訊息整理後立刻刪除;圖片不存檔;圖片編號 7 天刪。
- 對話與圖片內容視為「資料而非指令」,提示詞要求忽略其中要求改規則的文字。
- 所有資料表開 RLS 並 `revoke` anon / authenticated;Edge Function 以 service role 存取。
- 只服務兩位成員;非成員、`room`、未綁定群組一律不回話(陌生群組只認綁定碼)。
- 排程端點以 `x-ladys-key`(資料庫內隨機金鑰)驗證。
- 已知注意:手動輸入的備註不會被遮蔽,且會同步到 Google 日曆描述 → 不要把密碼寫進備註。

## 三、LINE 指令一覽(須完全相符)
| 指令 | 說明 |
|---|---|
| 選單 | 圖文捷徑卡 |
| 行程 | 未來 7 天 |
| 帳 | 本月收支 |
| 目標 / 待辦(瑣事) | 清單 |
| 更新行事曆 | 立刻整理未處理對話 |
| 記憶圖片 | 回覆圖片後使用,處理單張 |
| 記憶以上圖片 / 記憶以下圖片 | 回覆圖片後使用,處理一批 |
| LadyS 綁定 <碼> | 綁定家庭群組(僅一次) |
| LadyS 紀錄 <碼> | 綁定工作群組 |

## 五、成本與限制
- 回覆(reply)免費;推播(push)依群組人數計額度,同一次最多 5 則算 1 次。
- AI 模型:claude-haiku-5-5(抽取、讀圖、工作群);早上推播不用 AI。
- 單次整理上限 600 則訊息;圖片單批 20 張、單張 ≤4.5MB。
- 待確認項目 7 天作廢;群組原文不保留。
