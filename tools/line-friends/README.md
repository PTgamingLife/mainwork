# LINE 好友整理工具(lf_,僅限本機)

在自己的 Windows 電腦上,用 Playwright 開一個獨立的 Chrome 視窗載入 LINE 擴充功能,
**只讀**好友清單、狀態消息與近期訊息,存到本機 SQLite,再用規則 + Claude AI 分類。

- 網頁只綁 `127.0.0.1`,不對外開放。
- 聊天資料 `lf_data/`、登入 profile `lf_profile/`、擴充複本 `lf_ext/`、`.env` 都在 `.gitignore`,不會進 git。
- 唯一會修改 LINE 的動作是「改名」分頁(改你自己看到的顯示名稱),必須逐筆勾選確認並勾同意才會執行。
- 不會傳訊息、加好友、退群。

## 安裝與啟動(PowerShell)

前置:已安裝 Python 3.11+,並且在一般 Chrome 裡安裝過 LINE 擴充功能(工具會自動複製一份到 `lf_ext/`)。

```powershell
cd tools\line-friends
Copy-Item lf_env.example .env     # 第一次:打開 .env 填 ANTHROPIC_API_KEY
powershell -ExecutionPolicy Bypass -File .\lf_run.ps1
```

第一次會建立 `.venv`、安裝套件與 Playwright Chromium。之後同一個指令就能啟動,瀏覽器會自動打開 `http://127.0.0.1:8766`。
如果 port 被佔用,腳本會停下並告訴你是哪個程式;可以在 `.env` 設定 `LF_PORT`。

## 使用流程

1. **同步頁 → 開啟 LINE 登入**:跳出 Chrome 視窗,用手機 LINE 掃 QR 碼。
2. **更新好友清單**:讀名稱、狀態消息、聊天清單時間(不開聊天室)。
3. **開始這一批**:每按一次抓 100–200 人的近期訊息(預設每人 10 則),從上次停下的地方接著抓。
   預設略過有未讀訊息的聊天,避免對方看到「已讀」。
4. **跑規則分類 / AI 分類**:AI 只處理新的或內容有變動的好友。
5. **好友總覽**:篩選、搜尋、改分類(手動改的不會被同步覆蓋)、批次加標籤。
6. **好友詳情 → 個人深度分析**:在方框寫分析重點,可以先「抓更多訊息」(最多 300 則)再分析。
7. **改名**:提案 → 勾選確認 → 勾同意 → 執行;可以還原。

## 重要限制:LINE Chrome 版只有近期聊天

實測(2026-11):LINE Chrome 擴充登入後只同步**最近約兩週**的聊天(約 128 個聊天室),
不在聊天清單裡的好友,打開聊天室也是 0 則訊息。所以:

- **好友清單、狀態消息**:全部 4000 多位都抓得到。
- **近期訊息**:只有最近有聊天的人。保持登入一段時間,新訊息會持續累積。
- **更早的歷史**:請在手機 LINE 匯出聊天記錄 txt,用同步頁的「匯入聊天記錄 txt」補進來(重要客戶優先)。
- 其餘只有名稱和狀態消息的好友,仍可用規則分類;AI 分類會依名稱、狀態消息判斷(準確度較低)。

## AI 費用

預設模型 `claude-opus-5-5`。好友多、只需要粗分類時,可以在 `.env` 改成 `LF_AI_MODEL=claude-haiku-5-5`,費用低很多。
聊天內容會傳到 Anthropic,網頁上每次執行前都會提示。

## LINE 改版抓不到資料時

DOM 選擇器都在 `lf_selectors.json`。在同步頁按「偵測頁面結構」,會在 `lf_data/` 輸出目前畫面的 DOM 骨架
(所有文字已遮蔽成長度),依此修正選擇器即可,不需重啟伺服器。

## 備用:匯入 txt

LINE 聊天室 → 設定 → 傳送聊天記錄 → 存成 txt,在同步頁選取檔案(可多選)。

## 注意

LINE 的使用條款不鼓勵自動化操作。本工具刻意壓低頻率(每人隨機間隔 3–8 秒、一次一批、手動觸發),
但無法保證帳號完全不受影響,請自行斟酌使用量。
