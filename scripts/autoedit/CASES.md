## Case #1 — 2026-07-28 ⭐(直接對標:同樣是「用 Claude 剪片」)

**網址 / 帳號**:https://www.instagram.com/p/DaWz8luSmif/ ・@growithfyn(認證帳號)
**數據**:讚 8K / 留言 **22.3K**(留言>>讚,留言關鍵字「edit」機制爆發)・發布 2026-07-03
**這支在做什麼**:80 秒直式口播,主題就是「我只要說話,Claude code 就自動幫我剪片+對齊動畫+繁中英字幕」。**跟我們在做的工具是同一個概念**,是最佳對標範本。Caption 下「留言 edit 加入早鳥優惠」。

**字幕設計**(值得直接抄):
- **雙語**:每句中文(大、白字)+ 下方英文(小、灰白)兩行。
- **關鍵字 highlight**:句中重點詞染**黃/橘色**(如「8 位數」「動態圖像」「Claude」)。
- 置中偏下、細描邊、無底框。

**貼圖手法**(核心學習):
- **每一句都配一個貼圖**,而且**貼圖演出那句話的名詞/語意**:
  - 講「營收突破 8 位數」→ **金額計數器** `$10,000,000+`(黃字,裝在**深色圓角膠囊**裡,前面一個小icon)。
  - 講「動態圖像 / 剪輯軟體」→ **app 圖示貼圖**(Premiere 的 Pr、YouTube 播放鈕、`</>` code、晶片、攝影機、幾何圖形)。
  - 講「符合社群語言」→ **像素機器人吉祥物**圖示。
  - 講「把冷場空白剪掉」→ **紅黃條被剪斷的隱喻圖**。
- 圖示風格:**扁平/像素風、小尺寸、置中偏下(字幕正上方)**。
- **收尾 B-roll 上也照掛貼圖 + 字幕 + CTA**(不留白)。

**B-roll 手法**:
- 講到「生活/陪家人」時切**實拍生活 B-roll**(雨中划船、山林陪兒子)——B-roll 服務「不被螢幕綁住」的敘事,不是隨便插畫面。
- B-roll 期間**保留字幕 + 貼圖 + 釘住的 CTA**。

**節奏**:幾乎每 2–3 秒一個貼圖/畫面變化,全程沒有靜止死畫面。

**CTA / 版面**:
- **頂部固定黑色膠囊標題條**「Claude 幫我剪片+動畫繁中英字幕」——全片常駐,強化主題+當封面。
- 後段/結尾**釘住「留言:edit」**在底部。
- 一個 CTA(留言 edit),乾淨。

**可複用規則(已寫回 MODEL 第五章)**:
1. **每句配「演出語意」的貼圖**,優先用「名詞→對應圖示」:數字→計數器、軟體/工具→app logo、技能→人形、循環→迴圈…(正是我們 counter/ring/loop/flow/clone 的方向,再加 **app logo 圖示庫**)。
2. **雙語字幕 + 關鍵字黃色 highlight** 是這類 AI 教學帳號的標配,該加進我們的字幕引擎。
3. **計數器裝進深色圓角膠囊 + 小icon 前綴**,比裸數字更精緻。
4. **頂部常駐標題膠囊條** 強化主題與封面點擊。
5. **B-roll 只在敘事需要時切**(生活/對比),且 B-roll 上仍保留字幕/貼圖/CTA。
6. **釘住單一 CTA**(留言關鍵字),對照 reels 模型 Case #5/#6 的留言關鍵字機制。

## Case #2 — 2026-07-31 ⭐⭐(同作者進階版:動畫風格炫技示範)

**網址 / 帳號**:https://www.instagram.com/reel/DbcNK8asov8/ ・@growithfyn(認證,與 Case #1 同作者)
**數據**:讚 103 / 留言 **127**(留言>讚,關鍵字「大師」機制)・發布 1 小時・80.8 秒・1080×1920
**這支在做什麼**:炫技示範——「用 Claude Code 做出六套短影音動畫風格」。內容本身就是一連串精緻動態圖示的展示,是**動畫手法的教科書**。CTA:留言「大師」領加入連結。

**⭐ 影片架構(關鍵,跟 Case #1 不同)**:
- **上下分割版面**:上方 ~60% 是**純黑動畫畫布**(motion graphics 全在這裡演),下方 ~35% 是**講者小視窗**(圓角、暖色低調 moody 調色)。動畫不疊在人身上,而是有專屬舞台 → 動畫可以又大又乾淨。
- 少數強調句切**全屏講者**(換節奏)。
- **雙語字幕**卡在分割線上方:中文(粗白)+ 英文(小、大寫、寬字距灰)。
- 敘事弧:hook(模板全在動)→ 痛點(外包動畫貴:一支5萬/30秒、慢3-5天、只改2次)→ 解法(六套動畫風格)→ 功能(品牌字體/換配色/上架月曆)→ 願景收尾(成為世界1%)→ CTA(留言大師)。

**動畫手法(動畫方式)**:
1. **數字計數器 + 虛線弧**:「5萬」數字往上跳(帶動態模糊)+ 一圈**虛線圓弧**掃過,下方標籤。(我們 counter+ring 的合體升級版)
2. **清單卡片揭示**:深色圓角卡 + **紅色膠囊標題**(「外包的真實情況」)+ 紅色 ✗ 逐條列點。功能版用紅色 ▶。
3. **華夫格/點陣圖**:10×10 灰點 + 1 顆紅點,標「1/100 世界的1%」——單位圖表表達「1%」。
4. **裝置/模板牆**:一格格手機 mockup,每格各自播小動畫。
5. **App-UI mockup**:假的 Claude prompt 介面(含 Opus 4.8、送出鈕)、月曆 UI(即將上架 badge + 日期高亮)。
6. **大型動態字**:「六套動畫風格」「你的品牌字體」大粗字當主視覺。

**⭐ 視覺系統(跟我們現在的黃/綠不同)**:
- **深黑底 + 白字 + 紅色重點**(badge/✗/高亮點),灰色當次要/英文。整體 premium、editorial。
- 卡片=深灰圓角 + 細框;紅色膠囊 badge;英文小寫大寫寬字距。
- 講者暖色低光電影感;動畫畫布純黑高對比。

**可複用規則(寫回 MODEL 第五章)**:
7. **上下分割版面**是進階解:動畫放專屬黑畫布(上),講者縮小放下方 → 動畫更大更清楚,不擠在臉上。值得做成一個 render 模式。
8. **一套內聚的視覺系統**(這裡是黑+紅+白)比亂用顏色高級;我們該提供「主題」選項(黃綠活潑 vs 黑紅 premium)。
9. **痛點用清單卡 + 紅 ✗**、**功能用清單卡 + 紅 ▶**,是把「講道理」視覺化的高效模板。
10. **華夫格/點陣「1%」**、**計數器+虛線弧**、**大型動態字**、**假 App-UI mockup**、**月曆 UI**——六種新動畫型,補進我們的 stickers 庫。
11. **雙語字幕**(中粗白 + 英小寫寬字距)再次出現(Case #1 也是)→ 確認是這類帳號標配,優先做。

## Case #3 — 2026-08-01 ⭐⭐⭐(最高階對標:全螢幕交替 + 擬真 App-UI mockup)

**網址**:https://www.instagram.com/reel/DasnY6bB0Sw/ ・47.5 秒・1080×1920・Claude 吉祥物風格家族(同 @growithfyn 體系)
**主題**:Claude Code 的 Skills(5萬+ skills / Find Skills / Superpowers…),炫技示範等級最高的一支。

**⭐ 影片架構(比 Case #1/#2 更高階)**:
- **全螢幕交替**:不是固定上下分割,而是「**整頁動畫卡** ↔ **整頁講者**」輪流切。動畫要秀時吃滿全螢幕(更有衝擊),講者說話時全屏暖色木質背景。
- 少數 UI mockup 是**從畫面下方滑入疊在講者上**(半版)。

**動畫手法(要學的質感)**:
1. **大數字卡**:全黑底 +「50,000+」超大白字、「+」與「SKILLS」用**珊瑚色**、Claude 吉祥物、底部**放射狀光暈** + **點陣格線**紋理。
2. **動態字標題卡**:「SKILL 1 · Find Skills」大粗字 + 後方**淺灰 ghost 字**疊影(cream 底),章節分隔用。
3. **擬真 App-UI mockup**(最難、最加分):Claude Code 的 agent 面板(`Agent · Autonomous run` / `REVIEWING` + 檔案 diff 清單 `components/LoginForm.tsx +86`、綠勾)、檔案卡(roadmap.pdf/project/notes.md)、技能格牆。
4. **品牌吉祥物**:橘色 Claude 像素機器人,全片反覆出現當記憶點。
5. **雙語字幕 + 關鍵字highlight**(白字為主、次要字轉灰)。

**視覺系統**:深黑 + 米白 + **珊瑚橘(Claude 品牌色)**;點陣格線、放射光暈、大量留白;暖色木質講者畫面。

**可複用規則(寫回 MODEL 第五章)**:
12. **【最高階版面】全螢幕動畫卡 ↔ 全屏講者交替**:動畫要秀時吃滿全螢幕,比固定分割更有衝擊(適合炫技/清單型)。
13. **動態字標題卡**(大粗字 + ghost 疊影)當章節分隔,質感立刻上一階。
14. **擬真 App-UI mockup**(agent 面板/檔案 diff/檔案卡)是「等級」的關鍵——把抽象功能演成看得到的介面。
15. **品牌吉祥物 + 品牌色**(珊瑚橘)+ 點陣/光暈紋理 = 一眼認得的視覺識別。
